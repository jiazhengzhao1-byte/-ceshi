# 产品需求说明（PRD）

## 目标

- 开机即生效的本地拦截器，默认屏蔽：B 站（含直播域名）、斗鱼、虎牙、知乎、抖音。
- UI 随开机启动，提供 5min/10min/1h/2h 解除按钮。
- 1h/2h 每天各 1 次（本地 0 点重置）。

## 非目标

- 不做账号体系/云同步。
- 不做内容级屏蔽，只做站点/域名级别。
- 不保证已加载页面内容自动消失，但恢复屏蔽时尽量快速断连。

## 核心需求

### 默认屏蔽

- 服务启动后 1–3 秒内生效。
- 以域名集合定义，支持热加载或 UI 触发重载。

### 解除屏蔽 UI

- 常驻托盘，弹出小窗。
- 提供 5min/10min/1h/2h 四按钮。
- 状态展示：屏蔽中/解除中 + 倒计时（秒级更新）。
- 1h/2h 若已用，按钮禁用且显示“明日可用”。

### 立刻生效

- 不依赖 hosts/DNS 缓存。
- 点击解除后，新连接 <1s 内可通。
- 恢复屏蔽时主动断连，尽量让现有连接马上不可用。

### 状态机与规则

- 初始状态：屏蔽中。
- 解除后进入“临时解除中”，到期自动恢复。
- 5min/10min 的策略：叠加（可设累计上限，例如 2h）。
- 1h/2h：点击即消耗机会，跨天重置。
- 建议提供“提前恢复屏蔽”按钮。

### 权限与安全

- 服务以系统服务运行（高权限）。
- UI 以普通用户权限运行，通过 IPC 调用服务。
- 配置与状态存储在 `%ProgramData%/FocusBlocker/`。

### 可观察性

- 日志记录状态切换、按钮点击、到期恢复、异常（不记录访问内容）。
- UI 显示服务在线状态，服务崩溃自动重启。

## 技术路线

### 推荐：连接层拦截

- 基于 WFP 或包过滤驱动拦截连接。
- 通过 SNI/HTTP Host 匹配域名。
- 恢复屏蔽时触发断连（RST 或丢弃）。

### 备选：Windows 防火墙 FQDN 规则

- 成本低，但可能无法满足“立刻生效”的硬指标。

## 验收标准

1. 开机后不打开 UI，访问目标站点即被阻断。
2. 点击“解除 5min”，1s 内可打开目标站点（新请求）。
3. 解除期间点击恢复或倒计时结束后，刷新应立刻失败。
4. 1h/2h 当天仅可用一次，跨天恢复。
5. 服务重启后，倒计时与配额状态可恢复。
